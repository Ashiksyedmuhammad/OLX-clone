
**OLX-clone**

A React + TypeScript clone of the OLX classifieds platform. This project allows users to browse, list, and view products, leveraging Firebase for backend services and modern React architecture for scalable, modular code.

Features
Product Listings: Browse, add, and view products for sale.

User Authentication: Secure login/signup (powered by Firebase).

React Router: Seamless navigation between pages.

Toast Notifications: Feedback on user actions with react-toastify.

Modern UI: Styled with Tailwind CSS for a clean, responsive experience.

Component-based Structure: Logic separated by Components, Pages, and Contexts for maintainable and scalable code.

Tech Stack
Frontend: React 19, TypeScript, Tailwind CSS, React Router

Backend/Services: Firebase

Build Tools: Vite (for fast builds and HMR)

Notifications: react-toastify
